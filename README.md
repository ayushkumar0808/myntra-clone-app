# 🛍️ Myntra Clone – Frontend

A frontend clone of the **Myntra homepage** built using **HTML and CSS**.
This project recreates the look and feel of Myntra's landing page with a clean and responsive user interface.

## 🚀 Live Demo

👉 https://ayushkumar0808.github.io/mintra-clone-app/

## 🛠️ Tech Stack

- **HTML5** – Structure and semantic markup
- **CSS3** – Styling, layout, animations, and hover effects

## ✨ Features

- 🎨 Myntra-inspired homepage UI
- 📱 Responsive layout
- 🖼️ Product banners and categories
- 🔍 Navigation and search UI
- 🖱️ Smooth hover and zoom effects
- 📐 Flexbox-based layouts
- ✨ Clean and simple design
